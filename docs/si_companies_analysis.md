# 물류 자동화 및 상위 제어 시스템(MCS/WCS/ACS) 전문 SI 개발 기업 분석 보고서 (개정판)

본 보고서는 단순 설비 제조(HW) 중심 기업이나 고정 패키지 솔루션 판매 기업을 제외하고, **프로젝트별 맞춤형 소프트웨어 설계, 커스텀 SI(시스템 통합) 개발, 그리고 장비 연동 개발 용역을 직접 수행하는 전문 SI 기업 10곳**을 검증하여 재구성하였습니다.

---

## 1. 미라콤아이앤씨 (Miracom Inc.)
*삼성SDS 자회사로, 반도체/디스플레이/배터리 제조 물류(AMHS) 및 생산 관리 부문의 초대형 스마트팩토리 전문 SI 기업입니다.*

*   **SI 개발 형태:** 대형 제조사의 공정 구조에 맞춰 **Nexplant MCS/WCS** 등을 커스텀 SI 프로젝트 형태로 구축 및 개발 용역 수행.
*   **설비 제어 (SCS/LCS):** 다양한 물류 자동화 설비(Stocker, Lifter, 컨베이어)와의 물리 인터페이스 제어 모듈 개발.
*   **상위 스케줄러 (MCS/OHT/AMR):** OHT, AGV, AMR 군집 제어를 위한 복잡한 노선 라우팅 및 작업 스케줄러 자체 개발 및 연동.
*   **Java & UI/UX:** Spring, Netty 기반 실시간 소켓 통신을 다루는 Java 고급 개발자 대거 보유. 2D/3D 웹 표준 모니터링 UI 및 관제 화면 구축 역량 보유.

## 2. 에임시스템 (AIM Systems)
*반도체/FPD 등 미션 크리티컬 공장의 자동화 통합(CIM/MCS) 부문에서 독보적인 커스텀 SI 용역 개발 레퍼런스를 보유한 기업입니다.*

*   **SI 개발 형태:** 반도체/이차전지 생산 라인의 레이아웃과 이송 방식에 맞춰 스케줄러 및 제어 프로그램(**nexbe+ MCS**)을 100% 맞춤형 SI로 개발 및 구축.
*   **설비 제어 (SCS/LCS):** Stocker Control System, Lifter Control 및 로봇 핸들러 연동 제어.
*   **상위 스케줄러 (MCS/OHT/AMR):** OHT 반송 지시 최적화 알고리즘, AGV 교통 통제 스케줄러 개발.
*   **Java & UI/UX:** 초고속 데이터 트랜잭션 처리를 위한 Java 프레임워크 기반 설계 인력 및 3D 웹 디지털 트윈 관제 UI 기술력 보유.

## 3. 티라유텍 (Thira-Utech)
*제조/물류 IT 솔루션 전문 기업으로, 자회사를 통한 AMR 제조와 더불어 상위 제어/계획 시스템의 SI 용역 개발을 주력으로 수행하는 코스닥 상장사입니다.*

*   **SI 개발 형태:** 고객사의 기존 WMS, MES 시스템과 연동하는 커스텀 MES/MCS/WCS 통합 SI 프로젝트 개발 진행.
*   **설비 제어 (SCS/LCS):** 자동 창고 스태커 크레인, 리프터, 소터 등 이기종 하위 장비 제어 인터페이스 연동.
*   **상위 스케줄러 (MCS/OHT/AMR):** SEMI 표준 규격을 따르는 MCS와 다기종 AMR 군집 제어 스케줄러(Fleet Manager) 맞춤 설계.
*   **Java & UI/UX:** Java/Spring Boot 및 Web 백엔드 전문 고급 엔지니어 다수 보유. HTML5 기반 실시간 관제 및 로봇 대시보드 UI/UX 구현.

## 4. 포스코DX (POSCO DX)
*포스코 그룹 계열의 대형 IT/OT 융합 SI 기업으로, 대외 산업용 로봇 SI 및 스마트 물류센터 구축 프로젝트를 활발히 수주 및 자체 개발합니다.*

*   **SI 개발 형태:** 대형 유통 허브 터미널 및 제조 공장의 로봇/설비 시스템을 통합 설계하고, WCS/ACS 등 제어 소프트웨어를 프로젝트별 맞춤형 SI 개발로 공급.
*   **설비 제어 (SCS/LCS):** 소터 제어, 고속 리프터 제어, 자동 창고 연동 WCS(**SmartPOP**) 구축.
*   **상위 스케줄러 (MCS/OHT/AMR):** 자체 AGV/AMR 제어 시스템(ACS)의 스케줄러 및 무인반송 차량 경로 탐색 엔진 개발.
*   **Java & UI/UX:** 대용량 트래픽 및 실시간 제어 알고리즘 가용성을 보장하는 대규모 Java 시니어 인력과 3D 디지털 트윈 기반 관제 대시보드 UX 설계 보유.

## 5. 이삭엔지니어링 (Isaac Engineering)
*철강, 반도체, 2차전지 등 제조 전 영역에서 공장 제어 시스템(PLC, SCADA) 및 상위 물류 소프트웨어의 커스텀 SI 개발을 전문으로 하는 기업입니다.*

*   **SI 개발 형태:** 하드웨어 제조 없이 제어 소프트웨어 설계, PLC 코딩, 상위 MCS/WCS 소프트웨어 용역 및 SI 통합 구축 위주로 사업 영위.
*   **설비 제어 (SCS/LCS):** Lifter, Stocker, 갠트리 크레인, 컨베이어의 실시간 제어(HMI/PLC) 및 상태 분석 솔루션.
*   **상위 스케줄러 (MCS/OHT/AMR):** AGV/AMR 군집 주행 알고리즘 연동 및 자재 실시간 제어(MCS) 개발.
*   **Java & UI/UX:** 공정 연동 백엔드를 개발하는 Java 고급 엔지니어 및 SCADA/웹 표준 기반의 동적 모니터링 UI/UX 최적화 설계.

## 6. 링크제네시스 (Linkgenesis)
*설비 자동화 통신(SECS/GEM) 및 스마트팩토리 소프트웨어 SI 분야의 기술 중심 전문 기업입니다.*

*   **SI 개발 형태:** 반도체/디스플레이 장비와 상위 시스템 간의 통신/제어를 위한 CIM(Computer Integrated Manufacturing) 및 MCS 관제 소프트웨어 커스텀 개발 용역 수행.
*   **설비 제어 (SCS/LCS):** 장비 제어 드라이버 및 이기종 물류 설비 간 PIO 통신 연동 모듈 개발.
*   **상위 스케줄러 (MCS/OHT/AMR):** 상위 호스트(MES)의 지시를 수신하여 하위 OHT, Stocker 등으로 명령을 변환·배정하는 제어 시스템 개발.
*   **Java & UI/UX:** C++, Java 기반의 기계 통신(SEMI 표준 드라이버 개발) 및 백엔드 전문 개발자 다수 보유.
