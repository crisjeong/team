# 수원 소재 순수 소프트웨어 개발 용역 및 SI 전문 기업 분석 보고서 (개정판)

본 보고서는 패키지 솔루션 판매를 주력으로 하는 솔루션 업체를 완전히 제외하고, **고객사의 요구사항에 따라 Java 백엔드 및 UI/UX 화면을 직접 기획·디자인·개발하여 제공하는 순수 IT 아웃소싱 및 커스텀 SI 용역 개발 전문 기업 10곳**을 수원 지역 기준으로 선별하여 작성하였습니다.

## 1. 솔로몬텍 (Solomontech)
*수원시 영통구(광교)에 위치한 순수 시스템 통합(SI) 및 IT 아웃소싱 전문 기업입니다.*

*   **용역 개발 특징:** 솔루션 패키지 판매가 없으며, 기업의 비즈니스 요건에 맞춰 백엔드 설계부터 프론트엔드 연동까지 프로젝트 계약 기반으로 100% 주문 제작 개발을 진행합니다.
*   **Java 기술력:** Spring Framework/Boot 기반 고성능 API 서버 설계 및 복잡한 비즈니스 로직 최적화 역량 우수.
*   **UI/UX 기술:** Nexacro, HTML5 웹 표준 프론트엔드 퍼블리싱 및 모바일 반응형 관제 화면 커스텀 개발.

## 2. 노버스 (NOVUS)
*수원 소재의 디자인 및 기술 융합형 소프트웨어 개발 전문 에이전시입니다.*

*   **용역 개발 특징:** 기획서 검토부터 UI/UX 디자인, 개발, 퍼블리싱까지 턴키 외주 개발(SI)을 전문으로 하며, 중대형 웹/앱 시스템을 구축합니다.
*   **Java 기술력:** 대용량 트래픽 및 안전성이 요구되는 관리 시스템 구축 시 Java/Spring Boot 기반 백엔드 아키텍처 적용.
*   **UI/UX 기술:** 디자인 연구원 및 전문 디자이너 풀을 내재화하여 피그마(Figma) 기반 정밀 UI 설계 및 트렌디한 화면 UX 제공.

## 3. 가온소프트랩 (KaonSoftLab)

*   **주요 사업 영역:** 기업 전용 ERP/CRM 커스텀 빌드, 비즈니스 매칭 플랫폼 개발, 웹/앱 턴키 외주 개발.
*   **Java 기술력:** Spring Security, JPA 등을 이용한 기업용 보안 백엔드 설계 및 Java 기반 데이터 인터페이스 최적화.
*   **UI/UX 기술:** 사용자가 쉽게 사용할 수 있도록 대시보드 및 복잡한 테이블 화면을 구조화하는 관리용 UI/UX 디자인 능력 보유.

## 4. 어썸잇 (AwesomeIT)

*   **UI/UX 기술:** 모바일 터치 환경과 웹 접근성을 동시에 충족하는 사용자 친화적 그래픽 디자인(GUI) 및 인터랙션 모션 구현.

*   **UI/UX 기술:** 반응형 웹 UI, 다바이스 호환성(크로스브라우징) 및 웹 취약점 보완에 맞춘 고도화된 프론트엔드 퍼블리싱.
